# FORMA Studio

**Веб-конструктор планировок жилых домов с 2D/3D-просмотром и учебными инженерными расчётами.**

FORMA Studio — учебный проект о применении цифровых технологий для поиска эффективных проектных решений в строительстве. В редакторе можно собрать план дома до двух этажей, расставить проёмы, посмотреть интерьер и фасад в 3D, получить предварительные инженерные подсказки и экспортировать геометрию для FreeCAD.

> **Важно:** FORMA Studio — демонстрационный прототип, а не профессиональная система расчёта конструкций. Результаты встроенного расчётного модуля **нельзя использовать для реального строительства** без проверки инженером по действующим нормам.

## Возможности

- **2D-планировка:** создание, перемещение и изменение размеров прямоугольных комнат; привязка к сетке 25 см.
- **До двух этажей:** отдельное редактирование первого и второго этажа.
- **Комнаты и проёмы:** гостиная, спальня, кухня, санузел, коридор, кабинет; двери и окна.
- **Автоинтерьер:** визуальная расстановка мебели по типу и размерам комнаты; стили «Современный», «Сканди», «Лофт».
- **3D-просмотр:** вращение модели, просмотр интерьера и внешнего облика дома.
- **Виртуальный житель:** персонаж высотой около 180 см перемещается по доступным комнатам через двери, взаимодействует с предметами интерьера. Можно выбрать комнату назначения. Это демонстрационная симуляция, не полноценный симулятор поведения человека.
- **Предварительные проверки:** ориентировочные нагрузки, среднее давление на основание, предупреждения о пересечениях комнат и недостаточном опирании второго этажа, оценки тёплого пола.
- **История действий:** отмена и повтор изменений.
- **Сохранение:** экспорт и импорт проекта в JSON.
- **Экспорт для FreeCAD:** STEP по основной кнопке; дополнительные OBJ, STL и макрос FreeCAD.

## Запуск

Проект не требует установки Node.js, Python, npm или локального сервера.

1. Скачайте файлы репозитория.
2. Убедитесь, что `index.html`, `app.js` и `physics.js` находятся **в одной папке**.
3. Откройте `index.html` в современном браузере.

При первом запуске откроется демонстрационный дом. Изменения проекта сохраняются локально в браузере; для переноса на другое устройство скачайте JSON кнопкой **«Сохранить»**.

### Структура проекта

```text
forma/
├── index.html     # интерфейс, стили и резервный код запуска
├── app.js         # редактор, 3D, управление, навигация, экспорт
├── physics.js     # заменяемый модуль инженерных расчётов
└── README.md      # описание проекта
```

> В `index.html` есть резервный код для случая, когда браузер блокирует локальные скрипты. Для **подмены расчётов** оставляйте все три рабочих файла рядом: загружаемый `physics.js` имеет приоритет перед резервной реализацией.

## Как работать с редактором

1. Выберите тип комнаты слева и инструмент **«Комната»** (`R`). Нарисуйте помещение на плане.
2. Перейдите в **«Выбрать»** (`V`), чтобы перетаскивать комнату. Потяните за её угол, чтобы изменить размеры. Соседние комнаты могут касаться стенами, но не должны накладываться друг на друга.
3. Инструментами **«Дверь»** (`D`) и **«Окно»** (`W`) добавьте проёмы. Двойной клик по проёму удаляет его.
4. Переключайте этажи и виды **«2D + 3D» / «Только 2D» / «Только 3D»**. Справа можно включить **«Снаружи»**.
5. Откройте **«Анализ»**, **«Параметры дома»** или **«Тёплый пол»** для просмотра проверок и настроек.
6. В 3D включите персонажа и выберите комнату в списке **«Куда направить?»**. Для перехода между помещениями нужен доступный дверной проход; лестничная навигация между этажами пока не реализована.

**Горячие клавиши:** `Ctrl+Z` — отменить, `Ctrl+Y` или `Ctrl+Shift+Z` — повторить; `R` — комната, `V` — выбор, `H` — сдвиг плана, `D` — дверь, `W` — окно. Масштаб плана меняется колесом мыши или кнопками `+` / `−`.

## Замена физики одним файлом

Вся подключаемая расчётная логика размещена в `physics.js`. Её можно заменить на собственные алгоритмы **без изменения `app.js` или `index.html`**, если сохранить публичный интерфейс и формат результата.

### Контракт движка

В файле должен быть доступен глобальный объект:

```javascript
window.FormaPhysics = {
  calculatePhysics(project) {
    return {
      metrics: {
        groundArea: 0,
        upperArea: 0,
        totalArea: 0,
        rooms: 0,
        totalWallLength: 0,
        loadKN: 0,
        soilPressureKPa: 0,
        soilUtilization: 0,
        estimatedHeatKW: 0,
        criticalCount: 0,
        warningCount: 0
      },
      issues: [],
      heating: [],
      assumptions: []
    };
  }
};
```

Это **пример формата**, а не рабочий алгоритм: он возвращает нулевые показатели. Для настоящих расчётов необходимо использовать параметры из `project`, а полученные предупреждения и значения проверять.

**Входной объект `project`** содержит `rooms` (помещения с координатами, размерами, этажом и назначением), `openings` (двери и окна) и `settings` (материал, толщина стены, тип и параметры фундамента, теплопотребность и др.). Координаты и размеры указаны в **метрах**; этажи: `floor: 0` и `floor: 1`.

**Формат предупреждений** в `issues`:

```javascript
{
  severity: 'warning',  // critical | warning | success | info
  title: 'Проверка конструкции',
  detail: 'Описание проблемы или рекомендации',
  tag: 'Фундамент'
}
```

**Элемент `heating`** содержит поля `roomId`, `floor`, `name`, `area`, `heatedArea`, `heatNeedW`, `estimatedPowerW`, `pipeLengthM`, `loops`, `spacingM`, `coverage`. Массив `assumptions` содержит текстовые допущения расчётов.

**Порядок замены:**

1. Сделайте резервную копию текущего `physics.js`.
2. Замените вычисления внутри `calculatePhysics(project)` или весь файл, сохранив `window.FormaPhysics` и указанный контракт.
3. Сохраните `physics.js` рядом с `index.html` и `app.js`.
4. Перезагрузите страницу (при необходимости — с очисткой кеша).
5. Измените материал, размеры комнаты или параметры фундамента и проверьте, что показатели и предупреждения пересчитываются ожидаемым образом.

Встроенный модуль использует **сильно упрощённые учебные предположения**. Он не учитывает полностью снеговые и ветровые воздействия, армирование, осадки, грунтовые воды и многие другие обязательные факторы.

## Передача проекта в FreeCAD

**Для FreeCAD 1.0.1 на РЕД ОС** используется следующий основной сценарий:

1. В FORMA Studio нажмите **«FreeCAD · STEP»**.
2. Откройте скачанный `.step` в FreeCAD: **Файл → Открыть**.
3. При необходимости используйте команду подгонки вида под модель.
4. Сохраните открытый документ через **Файл → Сохранить как** в формате `.FCStd`.

В дополнительном меню экспорта есть OBJ, STL и FCMacro. **STEP — формат обмена геометрией; он не переносит все свойства строительной BIM-модели.** Макрос рассчитан на создание нативного документа средствами FreeCAD, но требует запуска в установленной программе.

> Совместимость STEP/макроса с конкретной установкой FreeCAD на РЕД ОС следует проверить отдельно. Прямой самодельный экспорт `.FCStd` намеренно не используется из-за ошибок совместимости.

## Ограничения

- Поддерживаются простые планировки и демонстрационная 3D-геометрия, а не произвольные BIM-объекты.
- Строительная физика и подбор отопления предназначены для образовательной демонстрации.
- Виртуальный житель не поднимается по лестницам между этажами.
- Качество WebGL-визуализации зависит от браузера и видеоустройства; при недоступном WebGL предусмотрен упрощённый режим отображения.
- Программа не заменяет архитектурный проект, конструктивные расчёты и техническую экспертизу.

## О проекте

Тема конкурсной работы: **«Эффективные проектные решения в строительстве ЖК (жилых комплексов)»**. FORMA Studio показывает возможный подход к цифровизации предварительного проектирования: модель помещений, визуализация, автоматическая первичная проверка и сменные расчётные алгоритмы.

Проект предназначен для учебной демонстрации и последующего развития.
