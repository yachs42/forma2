Заменить физику — один файл

Все расчёты теперь в одном отдельном файле physics.js. Компания может заменить функцию calculatePhysics(project) без сборки проекта и без изменений HTML или app.js.

window.FormaPhysics = { calculatePhysics(project) {
  return {
    metrics: { /* числовые показатели */ },
    issues: [],
    heating: [],
    assumptions: []
  };
} };

Открой physics.js текстовым редактором. Все нужные поля, входная структура проекта и пример готового алгоритма описаны в комментариях. Просто сохрани файл и обнови страницу.
